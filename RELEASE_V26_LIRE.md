# EURACONNECT V2.6 — Univers et catalogue adaptatif

## Inclus
- Catalogue avec univers violet, présentation compacte, responsive, cartes lisibles et actions prioritaires.
- Présentation automatique horizontale lorsqu’une seule offre est présente.
- Recherche, favoris, tri et choix grille/liste/compact dans une barre unique.
- Tris prix et nom appliqués sur les éléments **chargés sur la page uniquement** (pas sur la totalité du catalogue paginé).
- Pas de changement de droits Supabase, ni de migration SQL.

## Déploiement
Publier le contenu du dossier dans le dépôt GitHub lié à Cloudflare. Conserver les secrets de déploiement. Build : npm run build.

## Limites
- Les couleurs transversales pour les autres pages ne sont qu’amorcées : la refonte exhaustive de tous les univers reste à effectuer.
- Les descriptions Lorem ipsum proviennent des données et ne sont pas automatiquement remplacées.
- Recette navigateur connecté et vérification sur Supabase réel non réalisées.
