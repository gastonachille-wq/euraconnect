**Avant de déployer :** exécuter `supabase/migrations/202610140002_modules.sql` dans un environnement Supabase de recette. Ensuite importer les sources à la racine du dépôt GitHub et laisser Netlify construire.

Guide détaillé : `docs/INSTALLATION_V03.md`.

Cette version ne correspond pas encore à l'intégralité du cahier des charges V2 et n'a pas fait l'objet d'une validation de compilation/build ni d'une recette end-to-end sur le projet Supabase distant.
