# EURACONNECT V0.4 — Intermédiation

Livraison incrémentale sur V0.3. Modules ajoutés : référentiel de 9 compétences, affectation aux prestataires/besoins, matching explicable, messagerie après accord de mise en relation, suivi commercial partagé.

**Installer dans cet ordre** : migration `202610140003_intermediation.sql` sur une base de recette V0.3, puis déploiement du code sur Netlify. Ne pas remettre à zéro les données.

Documentation : `docs/INSTALLATION_V04.md`.

**Validation :** code généré ; la compatibilité sur une instance Supabase réelle et les règles RLS doivent être testées dans l'environnement cible avant production.
